# Experiment instructions

Do not modify the recorded results of a completed experiment. Create a new
experiment directory for a rerun or changed configuration.

For a notebook experiment, save only the executed notebook. Include one
clearly labelled experiment-record cell containing the research question,
hypothesis, complete configuration, provenance/manifest, explicit seed usage,
metrics, scientific summary, and exact reproduction command. Do not create
separate README, configuration, manifest, metrics, or summary files that
duplicate this cell.

For a non-notebook experiment, record the same information in suitable tracked
metadata files. Large generated artifacts remain outside Git.
