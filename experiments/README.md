# Tracked experiments

This directory contains experiments that form part of the thesis evidence.
Each experiment must record its research question, hypothesis, configuration,
provenance, explicit seeds, metrics, scientific summary, and reproduction
instructions.

An executed notebook stores this complete record in one labelled cell and is
tracked without duplicate sidecar files. Non-notebook experiments may use
separate metadata files. Large artifacts remain under `outputs/` and are
referenced from the experiment record.
