\subsection{Forecasting from synthetic priors: real-data evaluation}
\label{sec:foundation-prior-results}

\paragraph{Completed LMC training arms.}
The prespecified LMC reference runs are complete, while their matched
proposed-generator arms and real-data evaluations remain pending. Both used
seed 2021, a randomly initialized 119.48M-parameter Chronos-2, six channels,
96 context and 96 forecast steps, and a batch of 16. The shared configuration
SHA-256 is
\texttt{b18e5a493466307a33c516a9dd75fe00f7685b7572878b292ea9eda1912f60e4}.
The code revision was \texttt{1add431}; TimePFN was pinned to \texttt{e11d5c2}.
All 463 remote SHA-256 entries per run matched the received local files.
The full records are in
\texttt{experiments/generator\_model\_evaluation/prior\_lmc\_study\_a\_20261118.md}
and \texttt{prior\_lmc\_study\_b\_20261118.md}. The model repositories are
\url{https://huggingface.co/mateuswiteck/tsfmxai-chronos2-lmc-study-a-seed2021}
and \url{https://huggingface.co/mateuswiteck/tsfmxai-chronos2-lmc-study-b-seed2021}
(private at publication).

Study A prepared its corpus in 5,886.4~s outside the training clock, then
exhausted all 445,433 updates in 45,704.2~s (12.70~h), exposing 7,126,928
windows. Observed batch wait totaled 24.5~s. Study B began with an empty
run-specific cache and included generation in its ten-hour active budget.
It stopped after 299,991 updates, 4,799,856 windows, and 36,012.3~s
(10.003~h). Observed batch wait was 4,264.2~s (11.84\% of active time);
no LMC windows were repeated. Batch wait is not direct GPU stall. The
studies ran on separate RTX~4070 hosts with different CPUs, so their
throughputs are not a controlled machine comparison.

Table~\ref{tab:lmc-new-synthetic-validation} gives the last synthetic
validation measurement in each stage, each on 64 examples. It is neither a
held-out synthetic test nor a real-data score. The last correlated validation
precedes the final exported checkpoint in both runs. The independent-stage
validation loss in Study A rose after its observed minimum, a diagnostic
pattern compatible with overfitting; the final-budget model remains primary.

checkpoints. All use 2019: 255 eligible daily-grid windows at Ibirapuera and
357 in Bahia,
each with 96 context and 96 forecast hours. A dash denotes a model that has
not yet been trained and evaluated; it is not a zero error. The principal
generator comparisons will use LMC-Synth and this project's generator with
the same Chronos-2 backbone. The DLinear architecture is from
\citet{zeng2023transformers}, but its scores below were obtained in this
project with supervised fitting on 2014--2017 (air) or 2012--2017 (energy),
validation in 2018, and testing in 2019. It is not a published score for
either dataset. The DLinear training protocol was revised exploratorily after
preliminary 2019 inspection; these results should not be described as a
prespecified, independent benchmark. Both historical LMC checkpoints are

protocol uses its final budget checkpoint as the primary result. Neither
historical row represents a new matched-budget arm. The new LMC rows are
zero-shot evaluations of the two final checkpoints. The seasonal control
was evaluated on the same origins. Our generator has no measured entries

combined condition means equation head plus additional curriculum.

These 2019 scores are exploratory. Daily forecast windows overlap, so
the window count is not a count of independent trials. The DLinear training
cap was revised after preliminary inspection of 2019 outcomes, although
its final weights were selected on 2018 validation data. This is not direct
future-target leakage into optimization, but it limits the independence of
the 2019 comparison. No paired temporal-block interval for a
proposed-generator-versus-LMC contrast can be computed before the paired arm
exists. The historical cache state and step-indexed OneCycle scheduler
preclude treating the older checkpoints as the new time-matched LMC arm. The
new cold-cache LMC run, numerical ten-hour budget, scheduler, and decision
rule are recorded; the paired proposed-generator run remains outstanding. The
reviewer's inspection of the independent-stage learning curves found
decreasing training loss together with rising synthetic-validation loss
late in that stage. This pattern is compatible with overfitting, although
the small historical validation sample and incomplete local telemetry
preclude quantifying how much of the budget was unproductive. The new runs
record the full curves and the independent-stage terminal checkpoints.
