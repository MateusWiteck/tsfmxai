# Terminology

- **Generating mechanism:** executable mathematical rule that produces a
  trajectory from its state, inputs, parameters, and innovations.
- **Structural ground truth:** the variables and lags present in the retained
  mechanism.
- **Local contribution:** the realized contribution of a mechanism component
  for one input and forecast horizon.
- **Explanation ground truth:** a reference derived from the known mechanism
  against which an explanation can be evaluated.
- **Mechanism recovery:** estimation of an explicit mechanism from observed
  trajectories.
- **Model explanation:** description of why a fitted model produced a specific
  output; it need not equal the data-generating mechanism.
- **Prior:** distribution of synthetic tasks used for training.
- **Benchmark:** fixed generated task suite used for evaluation.
